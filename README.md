# Personal Portfolio Website

A modern and responsive personal portfolio website built using **React.js and Vite**, showcasing my professional background, technical skills, projects, experience, achievements, and leadership activities.

## ✨ Features

- **About Me:** Personal introduction and background.
- **Technical Skills:** Overview of programming languages, frameworks, and tools.
- **Projects:** Showcase of technical projects and implementations.
- **Experience:** Internships and professional experience.
- **Achievements:** Academic and technical accomplishments.
- **Leadership:** Leadership roles and extracurricular activities.
- **3D Models:** Interactive 3D visual elements.
- **Contact:** Connect for opportunities and collaborations.

## 🛠️ Tech Stack

- React.js
- JavaScript (ES6+)
- Vite
- CSS3
- HTML5
- Git & GitHub

## 🚀 Getting Started

### Prerequisites

- Node.js
- npm

### Installation

1. Clone the repository:

   ```bash
   git clone <YOUR_REPOSITORY_URL>
   ```

2. Navigate to the project directory:

   ```bash
   cd <PROJECT_DIRECTORY>
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL provided by Vite in your browser.

## 📦 Production Build

Build the project:

```bash
npm run build
```

Preview the production build:

```bash
npm run preview
```
